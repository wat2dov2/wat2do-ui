## Executive Summary

Participants generally found Wat2Do **easy to use** for browsing and saving events.
The homepage layout, organization filters, and heart/save interaction were intuitive.
Pain points clustered around **discoverability**: sort-by-date, calendar export, and search keyword matching.

### Task 1 — Find the most recent event and save it

- Most participants assumed events were already sorted by date or used organization filters to narrow results.
- The **sort control was hard to find**; one participant only discovered descending date sort after probing.
- Saving via the heart icon was understood once found; one participant wanted clearer confirmation that an event was saved.
- Ease ratings: mostly **1–2 out of 5** (1 = very easy).

### Task 2 — Search for a Jays game and add it to Google Calendar

- Finding a Jays-related event was usually easy when the event was visible on the homepage or when searching "Jays".
- **Calendar export was the hardest step.** Participants confused the overflow/download icon with share or generic download.
- Several expected a calendar-specific icon or visible "Add to calendar" / "Export" label without hovering.
- One participant initially thought "personal calendar" meant an **in-app calendar**, not Google Calendar.
- Searching **"Blue Jays"** often failed to surface the Jays game event — a keyword/tag gap.
- Ease ratings: mostly **2–4 out of 5**; calendar export drove the lower scores.

### Cross-session themes

| Theme | Sessions | Detail |
| --- | --- | --- |
| Sort vs filter | 1, 2, 3 | Sort-by-date is buried; users look under Filters first |
| Calendar export UX | 1, 2, 3 | Overflow/download icon reads as download or share, not calendar export |
| Search keywords | 2, 3 | "Blue Jays" misses events titled "Jays game" |
| Save confirmation | 2 | Heart turns red but no strong saved-state feedback |
| Saved events location | 2, 3 | Top-right Saved tab understood once pointed out |
| Search bar visibility | 4 | Easy to overlook at current size |
| Jason / AI chat | 1 | Purpose unclear; typing queries felt niche |
| Overall polish | 4 | "Really well designed"; minor UX tweaks only |

### Recommended improvements (from participants)

1. **Separate sort from filters** or expose "Sort by date" more prominently near the filter bar.
2. **Replace or label the calendar action** with a calendar icon and/or text like "Add to calendar" / "Export".
3. **Improve search/tag coverage** so related terms (e.g. "Blue Jays") match event titles and tags.
4. **Add save confirmation** — toast, badge, or clearer visual state after hearting an event.
5. **Enlarge the search bar** for first-glance discoverability.
6. **Clarify task wording** in testing (and in-product hints) when export targets an external calendar.
